# Public artifact policy

Public output is fail-closed: only files generated by an explicit export policy into a new empty directory are candidates for release.

## Never export

- ACVP credentials, client config, JWTs, TOTP state, PKCS#12 files or private keys.
- `secure-datastore/`, raw register/download/upload logs or command environments.
- User names, email addresses, phone numbers, postal addresses or local absolute paths.
- Raw ACVTS Demo requests/responses unless redistribution is separately reviewed and approved.
- `UNLICENSED` source, dependency caches, compiled output or old Git history.

## Allowed summary evidence

- Algorithm, revision, modes, parameter sets, functions and aggregate counts.
- Passed/failed dispositions without internal test-session or vector-set identifiers.
- SHA-256 hashes that link the summary to privately retained source evidence.
- Exporter version, policy hash, scan report and review attestation.

## Gates

1. Export into a new empty staging directory.
2. Verify expected modes, test counts and passed dispositions.
3. Run `tools/check_public_tree.py` and require zero findings.
4. Review every exported file manually.
5. Verify `SHA256SUMS` and record the review decision.
6. Repeat scanning against the final Git index and release archive.

`.gitignore` reduces accidental additions but is not a security boundary.
